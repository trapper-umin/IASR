# Абляция координации на отложенной конфигурации PostgreSQL

## Модели и сравнения

Полная per-action FQI уже зафиксирована по итогам [целевого пилота](../postgres-joint-pilot-2026-11-09/README.md). Аддитивная Q-функция имеет форму `Q(s,dL,dP) = qL(s,dL) + qP(s,dP)`. Оба слагаемых получают всю историю состояния. В каждом шаге FQI поочерёдно обучаются леса для дельт лимита на остатке после вычитания вклада пула и леса для дельт пула на остатке после вычитания обновлённого вклада лимита. Выполняются четыре прохода по обоим слагаемым. Первый вклад пула равен нулю. Seed лимита совпадает с seed шага, seed пула смещён на 100003.

Заморожены 974 перехода train и 160 переходов validation, а также параметры FQI из полной модели. Используются одинаковые вознаграждение, маска, преобразования и эмпирическая поддержка. Каждый балл вычисляется по 32 деревьям. В аддитивном варианте это по 16 деревьев каждого слагаемого. Они экспортируются в JSON v2 и выполняются тем же JVM-оценщиком. Общие леса переиспользуются при обучении, поэтому число уникальных деревьев и число наблюдений на лес различаются. Validation используется для диагностики, параметры по ней не выбираются. После обучения в протокол добавляется только SHA аддитивной модели.

Предварительно зафиксированы три попарных сравнения полной модели.

- С аддитивной при одинаковых доступных действиях и резервном AIMD. Это сравнение двух способов оценивать пары. Максимум в обеих политиках выбирает допустимую пару, и аддитивная политика тоже может менять оба ресурса одновременно.
- С той же полной моделью и фиксированным пулом 5. Меняются доступность действий над пулом и соответствующие границы в признаках, включая действия резервного регулятора.
- С AIMD, который регулирует оба ресурса. Это сравнение полной схемы с действующим базовым регулятором.

## Новые условия и измерения

Локальный PostgreSQL 17.10, нагрузка 63 запроса/с в течение 31,5 с после штатного прогрева. Запрос использует 320 000 строк. С 10,5-й до 24,5-й секунды стоимость вырастает до 720 000 строк. Начальный лимит 10, пул 5, свободные границы пула 2–12, SLO 150 мс, окна 1 с и такт пула каждые пять окон. Бюджет inference 20 мс. Эта конфигурация отличается от обучающих групп и от предыдущей отложенной серии.

Четыре блока по одному эпизоду каждого режима. Циклическая ротация даёт каждому режиму каждую позицию один раз. Основные метрики — goodput и клиентский p95 успешных ответов. Сохраняются также p99, нарушения SLO, 429, жёсткие отказы, восстановление, движения ресурсов и причины fallback. Восстановление отмечается после трёх подряд полных окон с серверным p95 ≤ 150 мс и goodput ≥ 56,7 запроса/с. Парные интервалы Стьюдента описательные, без поправки на множественные сравнения. Один общий хост и четыре блока ограничивают выводы.

Параметры и метрики сохранены в [протоколе](protocol.json).
