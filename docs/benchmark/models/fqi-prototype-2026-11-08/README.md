# Обученный прототип FQI

Модель обучена на [синтетических эпизодах](../../raw/fqi-prototype-2026-11-08/README.md). Код тренера: `c71b5edabad5496f5dc6e27c0b66dace601e0406`, рабочее дерево при обучении было чистым. Два запуска с одинаковыми входами дали байт в байт одинаковые `model.json`, `report.json` и `prediction-fixtures.json`.

Конфигурация зафиксирована до теста: 8 итераций, 32 ExtraTrees, глубина до 6, минимум 3 примера в листе, seed 42, gamma 0.95 за секунду. Параметры не подбирались по test. Преобразования обучены только на train; Rref = 237.9178. Вход дерева — 208 признаков истории/масок и 2 признака действия. Параметры, зависимости и SHA-256 входов находятся в `model.json`.

| Раздел | Всего примеров | Пригодно для условной Bellman-диагностики | Исключено |
|---|---:|---:|---:|
| train | 260 | 237 | 23 |
| validation | 160 | 139 | 21 |
| test | 160 | 146 | 14 |

Поддержка и пригодные переходы стабилизировались за три прохода. Число примеров, подтверждающих поддержку, равно числу использованных обучающих переходов. После восьмой итерации Bellman RMSE: train 0.382349, validation 1.213590, test 2.223856. Это условные ошибки Q-функции после фильтра поддержки, а не показатели производительности политики или оценка её ожидаемого вознаграждения. Среднее вознаграждение в отчёте относится к наблюдённым действиям исследующей политики.

JSON-предсказания совпали со sklearn на проверенных обучающих входах: максимальное расхождение 0.0. `prediction-fixtures.json` используется для проверки JVM inference. Никакой код pickle при загрузке модели не исполняется.

## Ограничивающий результат

При проверке на сохранённых историях изменение пула отсутствует во всех трёх разделах. На test из 160 историй: 131 предложение удержать оба ресурса, 24 — уменьшить конкурентность, 5 историй требуют fallback. Это offline предложения по уже наблюдённым историям. Последующая [техническая JVM-проверка](../../raw/jvm-policy-smoke-2026-11-08/README.md) сохранена отдельно и не подтверждает эффективность.

Поддержанные действия над пулом были доступны в 49 историях train и по 32 в validation/test. Поэтому отсутствие изменений пула не объясняется только маской. В экспортированном ансамбле 7 узлов используют признак изменения конкурентности и 0 — признак изменения пула. На этом наборе первый регрессор фактически не выделил влияние действия над пулом; согласованное обученное управление пока не продемонстрировано.

Результат сохраняется без перенастройки по test. Следующие исследования — расширение условий и покрытия train, анализ задержанного влияния пула и выбор параметров по validation. Для окончательного вывода понадобится новый независимый тест и замкнутый сравнительный эксперимент.

## Воспроизведение и следующий шаг

```bash
python3 docs/benchmark/tools/train_fqi.py /tmp/iasr-fqi-prepared --out /tmp/iasr-fqi-model --iterations 8 --trees 32 --depth 6 --leaf 3 --seed 42
python3 docs/benchmark/tools/fqi_runtime.py /tmp/iasr-fqi-model/model.json /tmp/iasr-fqi-prepared/test.jsonl
```

Версия происхождения в новом артефакте будет отражать checkout тренера; для побайтового совпадения происхождение и зависимости также должны совпадать. `train-decisions.json`, `validation-decisions.json`, `test-decisions.json` сохраняют аудит предложений. Модель помечена `deploymentAllowed: false`; последующая [JVM-итерация](../../../dissertation/jvm-policy.md) добавила контроллер, baseline fallback, бюджет и технический сквозной прогон. Пул модель по-прежнему не меняет.
