# Первая отложенная абляция координации

На чистом `07d0b38` выполнено 16 эпизодов по [замороженному протоколу](../../analysis/postgres-coordination-2026-11-09/README.md). Аудит подтвердил новую группу условий, SHA моделей, общий режим измерения, четыре полных блока и фактическую ротацию. Все четыре варианта запускались в одном процессе стенда на одном PostgreSQL.

Нагрузочные метрики усреднены по эпизодам. Задержки и нарушения SLO рассчитаны по успешным ответам, 429 — по отправленным запросам. Жёстких отказов в серии не было. Доля восстановлений использует критерий из протокола. Для эпизодов без восстановления наблюдение после деградации закончилось примерно через 6–7 с.

Свободный пул сопровождался меньшим p95 во всех четырёх блоках относительно той же модели с пулом 5. Порог восстановления при этом чаще достигался в варианте с пулом 5. У полной и аддитивной FQI оба интервала включают ноль. AIMD имел меньший p95 в каждом блоке, а интервал парной разности с полной FQI включает ноль.

В таблице только полные окна измерения. Варианты различаются по фактическим действиям модели. Вариант с пулом 5 сохранил этот размер на протяжении всех эпизодов, включая fallback. С учётом прогрева Python воспроизвёл все 378 решений моделей и 38 переходов на fallback по поддержке. Максимальное время inference составило 2,48 мс при бюджете 20 мс.

## Границы оценки

Выбрана одна новая конфигурация с изменением стоимости SQL. Goodput всех режимов снизился между первым и последним блоками. Ротация распределяет позиции, а четыре последовательных блока на общем хосте оставляют широкую неопределённость. Отдельная нагрузка на CPU СУБД в протоколе не измерялась. Пиннинг меняет и маску, и признаки границ пула. Полная и аддитивная FQI оценивают действие одинаковым числом деревьев, но используют разное число уникальных обученных деревьев. Парные интервалы описательные и без поправки на множественные сравнения.
