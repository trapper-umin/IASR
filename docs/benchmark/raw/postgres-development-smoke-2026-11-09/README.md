# Технический запуск новой модели на PostgreSQL

Один эпизод `spike/learned` выполнен на чистом `ddc0f7a` по [протоколу технической проверки](../../analysis/postgres-development-2026-11-09/live-smoke-protocol.json). Профиль уже использовался для validation на траекториях исследующего регулятора. Этот запуск проверяет подключение модели и действия в замкнутом контуре.

В 44 полных окнах фазы измерения модель приняла 43 решения. Она изменила лимит 12 раз и пул 5 раз, включая одно совместное изменение. Один fallback по поддержке также изменил оба ресурса. С учётом прогрева Python воспроизвёл все 48 решений модели и единственный fallback по поддержке. Максимальное время inference составило 2,73 мс при бюджете 20 мс.

В эпизоде goodput составил 85,7 rps, клиентский p95 — 169 мс, доля HTTP 429 — 41,5%. Один технический эпизод на знакомом профиле не устанавливает сравнительную эффективность. Стенд сохранил конечные записи и завершился с предупреждением Tomcat об остановке потока приёма соединений. Временный PostgreSQL остановлен.
