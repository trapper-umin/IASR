# Синтетические данные первого прототипа FQI

Сбор от 8 ноября 2026 года: `steady`, `spike`, `ramp`, `slow-dependency`, по четыре повтора режима `explore`. Исходники приложения — `ee31f96` (полный commit указан в metadata), рабочее дерево было чистым в момент старта сбора. Тренер разрабатывался отдельно во время работы уже запущенного приложения; исходники и скомпилированные классы Java в ходе сбора не менялись.

Настройки: 8 воркеров синтетической зависимости, базовое обслуживание 30 мс, исходный пул 6, минимум пула 2, исходный лимит конкурентности 22. `bench.epsilon=1`, `bench.policySeed=20261108`, `bench.orderSeed=42`. Полные длительности профилей, окно управления 1 с; прочие параметры — defaults приложения. Сон хоста блокировался `caffeinate -i`.

Это один синтетический объект, а не полный эксперимент на PostgreSQL. Результаты не доказывают превосходство обученной политики. Все действия и исходы принадлежат исследующей политике, а не обученной модели.

Сохранены 16 эпизодов и 774 записи, включая конечные записи. Валидатор обнаружил 628 полных измерительных переходов; четырёхоконные истории и маски дали 580 примеров.

| Раздел | Профили | Примеров |
|---|---|---:|
| train | steady, ramp | 260 |
| validation | spike | 160 |
| test | slow-dependency | 160 |

Разбиение построено с seed 42, профиль `slow-dependency` целиком зарезервирован для test. Группы не пересекаются; все четыре повтора каждого профиля остаются вместе. Общий журнал содержит все девять совместных изменений, но train после отбора содержит восемь: сочетание `[+1,+1]` в нём отсутствует и не может допускаться поддержкой модели.

```bash
python3 docs/benchmark/tools/validate_episodes.py docs/benchmark/raw/fqi-prototype-2026-11-08
python3 docs/benchmark/tools/prepare_dataset.py docs/benchmark/raw/fqi-prototype-2026-11-08 --out /tmp/iasr-fqi-prepared --seed 42 --test-scenarios slow-dependency
```

Сохранены `validation.json`, `preparation-manifest.json` и `coverage.json`. Полные подготовленные истории восстанавливаются из `episodes/`; их SHA-256 записаны в [модели](../../models/fqi-prototype-2026-11-08/README.md). Грубые диагностические области покрытия не устанавливают достаточность исследовательского набора.
