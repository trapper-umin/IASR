# Текст диссертации

Черновик ВКР «Интеллектуальное согласованное управление мягкими ресурсами серверного приложения на основе обучаемой политики», 15 ноября 2026 года.

| Файл | Содержание |
|---|---|
| `00-abstract.md` | реферат |
| `01-introduction.md` | введение: актуальность, цель, задачи, новизна, положения на защиту |
| `10-chapter1.md` | глава 1 — анализ предметной области и обзор (в том числе offline RL, SPIBB) |
| `20-chapter2.md` | глава 2 — постановка, базовый регулятор, единое описание ресурса, метод обучения, правило решения |
| `30-chapter3.md` | глава 3 — архитектура и реализация библиотеки и конвейера |
| `40-chapter4.md` | глава 4 — методика, результаты, мощность, подтверждающий прогон, угрозы валидности |
| `50-conclusion.md` | заключение |
| `90-appendices.md` | приложения А–Г |
| `references.json` | список источников (ГОСТ Р 7.0.5); номера присваиваются по первому упоминанию |
| `meta.json` | титульный лист |
| `figures/make_figures.py` | рисунки из архивов `docs/benchmark` |
| `build.py` | сборка `.docx` (Times New Roman 14, 1,5 интервала, поля 30/15/20/20 мм) и HTML-превью |

Сборка:

```bash
python3 docs/dissertation/thesis/figures/make_figures.py
```

```bash
python3 docs/dissertation/thesis/build.py
```

PDF-превью из HTML (WebKit macOS):

```bash
cd docs/dissertation/thesis && swift ../../paper/tools/html2pdf.swift Диссертация_IASR.html Диссертация_IASR.pdf
```

Ссылки на источники пишутся как `{key}`, перекрёстные ссылки — `[@tbl:id]`, `[@fig:id]`, `[@eq:id]`. Сборка останавливается, если ключ источника не найден или источник ни разу не процитирован.

## Что нужно дополнить вручную

- Титульный лист (`meta.json`): кафедра, направление и программа, группа, руководитель, заведующий.
- Сведения о публикации статей в разделе «Апробация» введения.
- Число страниц в реферате (`meta.json` → `pages`) после открытия в Word: оглавление и нумерация обновляются при открытии файла (Word спросит об обновлении полей).
- Требования вуза к объёму и оформлению; при необходимости — русскоязычные источники по обучению с подкреплением.
