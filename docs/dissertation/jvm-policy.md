# JVM inference прототипа FQI

Модуль `iasr-policy` реализует SPI `Controller` и читает переносимую JSON-модель без Python и sklearn в приложении. Он подключается явно; `iasr-core` не получил зависимости от Jackson. Модель остаётся исследовательским прототипом `deploymentAllowed: false`.

## Исполнение

`FqiModel` проверяет версию и порядок 208 признаков, нормализацию, размеры поддержки, индексы, связность и глубину деревьев. Дубликаты JSON-ключей, хвостовые значения, некорректные числа и несовместимые модели отвергаются при старте. Размер файла ограничен 8 MiB, поддержка — 10 000 векторов, лес — 256 деревьями / 200 000 узлами / глубиной 64. Сохраняется SHA-256 файла.

`LearnedController` хранит четыре последовательных наблюдения. Первая неполная запись, пропуск тика, некорректный cooldown или интервал за пределами `max(0.1 с, 25% окна)` сбрасывает историю. Пропуски обычных метрик кодируются маской, как в Python. Отсутствие обязательного контекста приводит к baseline.

Движок добавляет `observation_elapsed_sec` по `System.nanoTime()`, первое значение отсутствует (`null` в JSON). Это фактический интервал между полученными snapshot; он приближает окно агрегации поставщика метрик. Python использует его для новых записей; для старого архива сохраняется расчёт по timestamp. Номинальное окно остаётся отдельным признаком. Измерительные границы эпизода по-прежнему определяются wall clock.

Признаки округляются до float32 перед деревьями. Маска использует общий `JointActionSpace`, поддержку определяют число примеров/эпизодов и RMS-расстояние. При одинаковом Q выбирается меньшее изменение, затем исходный порядок кандидатов. Выбранное действие повторно проверяется с реальными границами actuator. Контроллер только возвращает предложение; применение остаётся в `ControlEngine` после guardrails.

Baseline вызывается на каждом тике, чтобы сохранять его временное состояние. При недостатке истории/поддержки, ошибке или истечении бюджета возвращается его предложение с причиной `learned_fallback_*`. Ошибка загрузки модели завершает старт режима `learned`. Журнал сохраняет различие между решениями модели и baseline; metadata содержит SHA модели и итоговую статистику inference.

Бюджет по умолчанию 20 мс относится к подготовке признаков, поиску поддержки, оценке леса и проверке кандидата; baseline в него не входит. Проверки времени кооперативные, внутри ограниченных циклов, без фоновых потоков. Это не жёсткая гарантия реального времени: GC, планировщик и отдельный участок между проверками могут увеличить наблюдаемую длительность. Превышение завершает inference на ближайшей проверке и вызывает baseline.

## Воспроизведение

```bash
mvn --offline clean verify
python3 -m unittest discover -s docs/benchmark/tools -p 'test_*.py'
# Перед exec:java установить текущие модули в локальный Maven repository:
mvn --offline install -DskipTests
mvn --offline -pl iasr-benchmark exec:java \
  -Dbench.modes=learned,adaptive -Dbench.scenarios=steady,spike -Dbench.repeat=1 \
  -Dbench.allowPrototype=true \
  -Dbench.model=docs/benchmark/models/fqi-prototype-2026-11-08/model.json \
  -Dbench.inferenceBudgetMs=20 -Dbench.poolPeriod=5 \
  -Dbench.db.workers=8 -Dbench.db.serviceMs=30 \
  -Dbench.poolSize=6 -Dbench.poolMin=2 -Dbench.initialLimit=22 \
  -Dbench.orderSeed=42 -Dbench.out=/tmp/iasr-jvm-smoke
```

Экспортированные 67 Python-историй проверяют точное совпадение float32-признаков, маски, поддержки и решения; численные Q проверяются с допуском `1e-12`. Отдельные 16 входов сверяют лес с экспортом sklearn. Генератор `export_jvm_fixtures.py` восстанавливает первые проверки из подготовленного архива. Тесты контроллера проверяют прогрев, сброс истории, fallback, бюджет и последующее применение guardrails.

## Граница результата

Подключение модели к замкнутому контуру не означает подтверждение гипотезы. Сохранённый первый лес не использует признак действия над пулом. Для результата диссертации нужны более содержательные train-данные, настройка по validation, новая независимая оценка совместных действий, абляции и повторный эксперимент PostgreSQL с текущим определением задержки.
